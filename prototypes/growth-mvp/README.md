# movemate — Growth MVP ("내 방 카드")

무브메이트의 핵심 과제 **"개인이 어떻게 사람을 끌어모으나"**에 대한 답을 제품으로 구현한 MVP.

> 이사는 1~2년에 한 번 쓰는 **저빈도 서비스**라 그 자체로는 사람을 붙잡지 못한다.
> → **평소에 자랑하고 공유하는 "내 방 3D 카드"**를 훅으로 삼아 사람을 모으고,
>   그 트래픽을 **이사 견적 → 업체 연결 커미션**으로 수익화한다.

설치 없는 웹 1장으로 **스캔 → 3D 미니룸 → 이사 견적 → 공유/초대**의 바이럴 루프를 끝까지 보여준다.

---

## 실행

정적 파일이라 빌드 불필요. 폴더에서 정적 서버만 띄우면 된다.

```bash
cd prototypes/growth-mvp
python3 -m http.server 8777
# → http://localhost:8777
```

> `room-data.js`를 ES module로 import 하므로 `file://` 직접 열기는 막힌다. 반드시 http 서버로 열 것.
> **Three.js는 `vendor/`에 로컬 내장** → 인터넷 없이도 작동(CDN 의존 제거). 비행기·방화벽·오프라인 OK.

### 배포 (개인이 오늘 당장)
- **Vercel / Netlify / GitHub Pages** 에 이 폴더를 그대로 올리면 끝(빌드 설정 없음).
- 공유 카드/초대링크가 곧 광고이므로, 배포 → 링크 뿌리기가 1번 액션.

## 화면 흐름 (바이럴 루프)

| 단계 | 화면 | 성장 관점 역할 |
|---|---|---|
| 0 | 히어로 + 갤러리("남의 집 구경") + "무료로 내 방 만들기" | 후크 — 마찰 0, 소셜증거/부러움 |
| 1 | 스캔 연출 → **3D 미니룸**(합성 데모 방) + 이 방 가구/부피/무게 | **와우 포인트** — 자랑거리. 1차 CTA=공유 |
| 2 | **이사 견적** — 정직하게 "이 방 하나 기준"부터, **방을 추가하면 우리집 전체 견적**으로 합산 | 수익화 + **저빈도 리텐션**(방 추가=재방문/집 전체 데이터) |
| 3 | **공유 카드 PNG**(이 방 짐 부피·무게, 과장 없음) · 카카오 · **친구 초대(둘 다 프리미엄)** · 웨이팅리스트 | 바이럴 루프 + 데이터 수집 |

> **왜 "방 하나"가 아니라 "우리집"인가:** 방 하나에 이사 견적을 단정하면 과장이다(이사는 집 전체).
> 그래서 방 1개는 정직하게 "이 방 기준"으로만 보여주고, 거실·주방·침실을 추가할수록 진짜 전체 견적이 된다.
> 이 "방 추가" 행동이 저빈도 서비스의 약점인 **리텐션을 만들고**, 팀이 원하는 **집 전체 공간 데이터를 수집**한다.

## 구성

- `index.html` — 앱 전체(히어로+**갤러리** · Three.js 돌하우스 미니룸 · 이사 견적 · 공유 카드 PNG · 초대/웨이팅리스트)
- `landing.html` — **프로그래매틱 SEO 랜딩 데모**(`?region=&size=`). 지역×평형 조합이 한 템플릿으로 자동 생성 → 앱으로 전환
- `room-data.js` — 합성 방 경계 + 대표 가구 9종 + 갤러리 4채 + 이사 견적 산출
- `GROWTH_STRATEGY.md` — ⭐ 리서치 기반 "사람 끌어모으기/설득" 전략 결론(핵심 산출물)
- 원시 리서치 자료와 내부 출처 메모는 이 코드 저장소에서 제외

### 검증 (headless Chrome로 자동 테스트됨)
- `index.html?selftest=1` → 견적/갤러리/공유카드PNG/초대코드/통계/폴백/이메일검증 **10개 자동 테스트** (#diag에 PASS/FAIL)
- `index.html?auto=room|est|share` → 각 단계 자동 진행(렌더 검증/데모용)
- **WebGL 미지원 기기**에서도 2D 평면 폴백으로 퍼널이 살아남음(검증 완료)

## 데이터/로직 메모

- 방 경계는 고객·주거 데이터를 포함하지 않는 합성 L자형 예시다.
- 이사 견적 = 가구 부피 합 × 적재계수(2.4) → 트럭 대수 → (트럭비 + 무게비례 인건비). 데모용 투명 근사치.
- 초대코드/웨이팅리스트는 `localStorage` 데모(서버 붙이면 그대로 실서비스화 가능).
