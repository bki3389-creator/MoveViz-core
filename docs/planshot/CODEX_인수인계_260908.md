## 3. 코드 맵 (apps/web-minibim/js/)
- `state.js` — 프로젝트/평면 데이터 모델·편집 연산(벽 이동/분할/코너·개구부·가구)·undo·직렬화. **스키마 필드 절대 삭제/개명 금지**(iOS·링크 호환): boundary/xw/zw/openings(dk·dm·flip·span)/furniture(existing·status·replaced)/wallOverrides/wallTypes/finishColors/marginPct
- `catalog.js` — 마감·조명·공사항목 단가 카탈로그, ORDER_PACKS(발주 포장단위), CREW_SEQ(공정 순서)
- `estimate.js` — 견적 엔진(buildEstimate)·이윤행·내 단가표 병합·발주(buildOrderList)·일정(buildSchedule)·CSV
- `plan2d.js` / `scene3d.js` — 2D 캔버스 편집 / three 3D(걷기·천장 링·텍스처). **scene3d는 node로 import 불가**(bare specifier)
- `render.js` — three-gpu-pathtracer 실사 렌더. env는 **Float DataTexture만**(CanvasTexture는 크래시), 세대 토큰(gen)으로 중단 제어
- `dxf.js` — R12 DXF 발행(실무 레이어 A-CON/A-FIN·치수 2단·A3 도곽). **레이어명에 공백·마침표 금지**(캐드 멈춤 이력)
- `ai.js` — Claude 비전 대화형 디자이너(키는 localStorage, 프록시 폴백은 config.js AI_PROXY_URL)
- `mode.js` — 양면 모드(home/pro) 상태·쉬운말 사전. `share.js` — 고객 링크(#r= deflate) 코덱. `biz.js` — 사업자 프로필·내 단가표(localStorage)
- `main.js` — 전체 UI 배선(부팅 순서 민감 — 고객 링크 선차단 로직 있음). `textures.js` — 절차 텍스처 12종

## 5. 작업 규칙 (필수)
1. 수정 후 **반드시** `node apps/web-minibim/tests/run_all.mjs` 전체 통과 확인 — 실패 상태로 푸시 금지(푸시=라이브 배포)
2. 3D/UI 변경은 헤드리스 스모크: `chrome --headless=new --user-data-dir=<새폴더,절대경로> --virtual-time-budget=15000 --screenshot=x.png "http://localhost:8899/?mode=pro"` + 콘솔 stderr에서 오류 grep. URL 파라미터: `?sample &mode=home|pro &tab=2d|3d &rendershot=N`
3. **스키마·저장 포맷 변경 금지**, 새 필드는 추가만(로드 시 normalize). 이벤트 버스는 `on(fn)` 단일 리스너에 what 인자 필터 방식(on('이름',fn) 아님)
4. 견적 불변식 유지: Σrows.amount=sub, subM+subL=sub, total=sub+vat (test_pro가 검증)
5. `state.customerView`/`state.noAutosave`(고객 링크 뷰), `body.mode-home|mode-pro|customer` 클래스가 가시성 단일 진실 — JS 분기 최소화, CSS로 숨김
6. 커밋은 한국어 요약 + 작은 단위. force push 금지. main 브랜치 건드리지 말 것
7. 렌더/텍스처 등 무거운 검증은 픽셀 통계(PIL)로 — 스크린샷 육안 의존 금지

## 7. 함정 (아는 데 오래 걸린 것들)
- 렌더샷: 첫 셰이더 컴파일 10초~2분 정상. 조명·천장은 렌더에서 강제 켬(라이브 설정 무관)
- W: 드라이브(회사) 금지 — 이 프로젝트는 개인, 산출물은 repo 안에만
- 헤드리스 크롬 user-data-dir는 **절대경로**(상대경로면 조용히 실패)
- `?sample` 파라미터는 테스트가 쓰는 고정 경로 — 시맨틱 바꾸지 말 것
- share.js 링크는 URL 해시(#r=) — 서버·쿼리스트링 아님. 100KB 초과 시 null 반환이 정상
