# 실제 공간을 결정하는 작업실 — 2026-09-08

앞선 공간 제안 페이지는 스타일 사진을 보여주는 데 치우쳤고 실제 편집 경험은 그대로였다. 이번 변경은 실측 모델에서 마감과 비용을 결정하고 그 결과를 고객에게 전달하는 흐름을 앱의 기본 진입점으로 만든다.

## 사용 흐름

1. **공간**: 실측 JSON을 불러오거나 샘플을 열고 방을 선택한다. 전체 실측 모델, 공간 면적과 가구·조명 수를 확인한다. 도면·구조·가구 편집은 상세 편집에서 계속 사용한다.
2. **디자인**: 선택한 방을 확대한다. 마감 조합 또는 바닥·벽·천장 재료와 색상을 고르면 실제 모델과 전체 공사비가 즉시 바뀐다. 변경 전후 이미지를 직접 드래그해 비교하고, 마지막 변경이나 처음 마감을 복원한다.
3. **견적**: 공간별 공사비, 공통 비용·제경비, 부가세를 확인한다. 상세 단가 수정도 상단 총액에 반영된다. CSV·상세 견적 인쇄·업체 설정을 이용할 수 있다.
4. **제안**: 현재 실제 모델과 마감·물량·금액을 제안서로 확인한다. 현재 안을 고객 링크로 복사하거나 실제 모델이 포함된 제안서를 인쇄한다. 고객의 비교·상담 내용 복사는 발송 원본을 바꾸지 않는다.

## 진입 경로

- 기본 `/`, `?mode=pro`, `?mode=home`: 작업실
- `?mode=pro&view=studio&step=design`: 디자인 단계 바로 열기
- `?view=proposal`: 제안서
- `#r=...`: 기존 읽기 전용 고객 링크 → 제안서
- `?view=editor`, 기존 `?sample&mode=pro&tab=2d`, `?rendershot=N`: 기존 편집·검증 경로 유지

## 코드와 저장 계약

- `studio-template.js`, `studio.css`: 작업 단계별 화면과 반응형 레이아웃
- `studio.js`: 실제 상태·마감·전후 비교·견적·제안서 연결. 고객 모드의 변경 동작 차단
- `studio-model.js`: 마감 변경/복원/비교 계산. 입력 프로젝트를 직접 변경하지 않음
- 추가 저장 필드 `project.designBaseline = { version: 1, rooms: { [roomId]: { floorFinish, wallFinish, ceilFinish, finishColors } } }`. 각 방에서 처음 마감을 바꾸기 전 기준을 기록한다. 읽을 때 마감 필드만 허용하며 구조·가구·단가를 덮어쓰지 않는다. 기존 필드 삭제·개명 없음
- `scene3d.js`: `setScenePresentation(enabled)`, `frameRoom(roomId)`. 중립 배경·그림자·가구 표현·선택 공간 확대·카메라 방향에 따른 앞벽 숨김. 저장 모델을 변경하지 않는다
- `render.js`: 실사 렌더용 복제 모델에서는 작업실의 임시 벽/방 숨김을 해제한다
- `proposal.js`: 현재 작업안을 기본으로 표시. 참고 사진은 별도 보조 보기. 제안서 인쇄는 실제 모델과 공사 내역을 포함한다
- 견적은 기존 `buildEstimate`를 그대로 사용한다. 저장/공유 시 유효한 회사 단가·이윤을 프로젝트에 고정한다

## 검증

- 필수: `node apps/web-minibim/tests/run_all.mjs` (13파일)
- 실제 사용 흐름: 서버 실행 후 `node apps/web-minibim/tests/browser_proposal.mjs`
- Chrome 검증은 테스트 디렉터리 아래 절대경로의 임시 프로필 사용. 실측 파일 입력 → 실제 마감 변경 → 되돌리기 → 직접 드래그 비교 → 단가 수정 → 같은 금액의 제안서 → 고객 링크, 데스크톱/390px 모바일, 기존 샘플 경로를 확인
- 제안서 인쇄는 2페이지 PDF를 렌더해 실제 모델·전체 공간별 비용·상세 내역을 확인
- 별도 3D 점검: 방 전환, 전체 보기, 모드 해제 시 가시성 복원, 음수 좌표, 좁은 화면의 모델 배치, 숨겨진 객체의 클릭 차단, 캡처 시 상태 불변

## 현재 범위

실제 모델의 건축 모형 표현과 작업 흐름을 개선했다. AI가 현장 사진을 실사 리디자인하는 기능은 이번 변경에 포함되지 않는다. 참고 사진은 실제 현장 렌더가 아니라고 표시한다. AI 요청 안정성, 렌더 갤러리, 2D 두 손가락 조작, 모바일 걷기는 별도 후속 작업이다.

자동 배포를 발생시키는 원격 푸시는 하지 않았다.
