# 공간 제안 화면 — 2026-09-08

## 목적

첫 화면에서 대표 공간의 분위기, 바뀌는 마감, 실제 견적 차액을 함께 보여준다.
시공자는 비교한 안을 현장에 적용하거나 고객용 링크로 전달하고, 고객은 원본을 유지한 채 다른 안의 상담 내용을 복사한다.

## 열기

- 제안 화면: `http://localhost:8899/?mode=pro&view=proposal`
- 기존 작업실: `http://localhost:8899/?mode=pro&view=editor`
- 기본 진입은 제안 화면. 첫 방문의 빈 프로젝트에는 프로 샘플을 불러온다.
- 기존 `?sample`, `?tab=2d|3d`, `?rendershot=N` 진입은 작업실 동작을 유지한다. `view=proposal`로 명시하면 제안 화면을 연다.
- 기존 작업실 상단 **공간 제안** 버튼으로 돌아갈 수 있다. 고객 `#r=` 링크는 제안 화면으로 열린다.

## 구현 범위

- 오크 강마루·크림 실크벽지와 밝은 포세린·화이트 도장, 두 가지 고정 마감 제안.
- 대표 건식 공간 선택, 동일 기준의 전체 현장 예상 비용·차액·방별 상세 비용.
- 비교 중에는 원본을 변경하지 않으며, 적용 버튼에서 마감과 견적을 함께 반영한다.
- 제안 전 마감 복원, 적용 단위 Ctrl+Z, 저장·공유 시 유효 단가와 이윤 고정.
- 이미지 → 실제 실측 모델 전환. 모델은 선택한 마감으로 별도 구성하고 동일 구도의 모형 뷰로 표시한다.
- 고객은 디자인 비교와 상담 내용 복사만 수행한다. 자동저장·편집·단가 변경을 차단한다. 복사는 시공자에게 자동 전송하지 않는다.
- 모바일 390px, 주요 터치 영역 44px, 키보드 포커스 및 상태 알림.

## 이미지와 견적의 의미

`assets/proposal/warm.jpg`, `calm.jpg`는 내장 image_gen으로 생성한 **스타일 참고 이미지**다. 업로드한 실측의 사진·정밀 렌더가 아니다. 화면에 이 구분을 표시하며 실제 구조·가구 배치는 실측 모델로 확인한다.

이미지의 장식·가구를 구매 견적에 추가하지 않는다. 이번 제안은 바닥·기본 벽·천장 마감만 바꾸고 가구·조명·구조 및 개별 지정 벽은 유지한다. 전체 비용은 해당 현장의 기존 공사 범위까지 포함한 참고 견적이다.

정확한 생성 프롬프트와 이미지 저장 경로는 [이미지 제작 기록](../../apps/web-minibim/assets/proposal/README.md)을 참고한다.

## 코드

- `js/proposal-template.js`, `css/proposal.css`: 이미지 중심 제안 화면.
- `js/proposal.js`: 비교·적용·복원·고객 상담·작업실 연결.
- `js/proposal-model.js`: 원본을 바꾸지 않는 제안 계산과 마감 스냅샷.
- `js/estimate.js`, `state.js`: 선택 프로젝트를 명시적으로 전달하여 공유벽 수량까지 같은 기준으로 계산.
- `js/scene3d.js`: 별도 공간 미리보기. 기존 카메라 복원, 임시 텍스처 정리, 제안 화면에서는 숨긴 작업실 렌더 중지.
- `project.proposal`: version, roomId, selectedStyle, baseline, applied 마감 필드만 추가. 마지막으로 확정한 대표 공간의 비교 기준을 저장한다.

## 검증

```powershell
node apps/web-minibim/tests/run_all.mjs
node apps/web-minibim/tests/browser_proposal.mjs
```

도메인 검증은 12파일이다. 브라우저 검증은 실행 중인 `serve.py`, Node 22+, Chrome/Edge가 필요하다. 기본 경로에 브라우저가 없으면 `CHROME_PATH`를 지정한다. 테스트가 절대경로의 격리 프로필을 생성하고 종료한다.

브라우저 검증: 데스크톱/390px 모바일, 비교 중 원본 유지, 모델 렌더, 적용/Undo/복원, 스캔 추가 시 Undo 경계, 실제 공유 핸들러, 고객 금액 일치·원본 불변·자동저장 보존·키보드 단가 차단, 기존 샘플 경로.

화면 및 모델 캡처는 `apps/web-minibim/tests/.out/proposal-smoke/`에 저장한다. 모델 픽셀 검증에서 기준/제안 양쪽의 명도 표준편차가 29 이상이며 변경 픽셀 비율이 약 14%로, 빈 이미지나 동일 이미지가 아님을 확인했다.

## 다음 확장 지점

현재는 고정 스타일 참고 이미지와 실제 마감 계산을 연결한 첫 제안 경험이다. 현장별 이미지 생성, 공간별 여러 제안의 지속 보관, AI 대화에서 이 비교 화면으로 제안 전달은 별도 확장 대상이다.
