## 2. 데이터 시드 통합 — "데이터 0"을 "국가 기준 탑재"로 뒤집기

리서치로 확정된 무료·즉시 소스 4종. 전부 자동승인/무가입 다운로드, 실측 검증됨.

### S1. 노임단가 — 대한건설협회 2026 상반기 (반나절) ★즉시
- **실수치 확보됨**: 도배공 227,614 / 타일공 290,939 / 도장공 263,017 / 내장공 256,883 / 건축목공 277,642 / 미장공 277,276 / 보통인부 172,068원 (1일, 지정통계 승인 제365004호)
- 구현: catalog.js `DAY_RATES`를 이 공표치로 교체 + 견적서·일정에 **"노무비: 대한건설협회 2026 상반기 시중노임단가 기준"** 표기. 공공 원가계산과 동일 근거 = B2B 신뢰 최상.
- 갱신 자동화 로드맵: KOSIS OpenAPI(orgId=365, tblId=TX_36504_A001_1, 키 즉시발급).

### S2. 표준품셈 — 국토부 2026 (1~2일)
- CODIL 원문 PDF 무료(로그인 불필요), 도배(5-3-7)·타일(3-2)·목공(4장)·PVC바닥(5-1-1)·도장(11장) 실측 확인.
- 구현: 인테리어 공종 노무량(품/㎡)을 발췌 테이블화 → 우리 laborDays 검산 + **"국토교통부 표준품셈(2026) 기준 노무량"** 배지. 공정 일정의 근거가 '감'이 아니라 국가 적산 기준이 됨.

### S3. 자재단가 — 조달청 나라장터 가격정보 API (2~3일)
- 무료 오픈API 자동승인(15129415 조사가격 + 15129471 계약가격). 벽지·바닥재·타일·조명 커버.
- 구현: 80품목 ↔ 조달청 물품분류 매핑 시드 JSON → **기준단가 편차 배지의 기준을 "조달청 2026 상반기 가격정보"로 승격** (지금은 자체 표준 단가표). CORS 때문에 프록시 워커에 `/v1/prices` 라우트 추가(캐시 1일).
- 데모 대사: "이 견적의 자재단가는 조달청 조사가격 기준 −3%입니다."

### S4. 건축물대장 — 건축HUB API (1일) ★데모 임팩트 최대
- 엔드포인트 검증됨: `apis.data.go.kr/1613000/BldRgstHubService/getBrTitleInfo` (+전유부 면적). 자동승인, 일 10,000건.
- 구현: 스튜디오 온보딩에 **"주소 입력"** 필드 → 준공년도(useAprDay)·구조·전유면적 자동 →
  - "**준공 2001년, 25년 경과 — 설비·배관 교체, 철거 후 재시공 권장**" 항목 자동 제안 (연식 규칙표: 15년+ 도배·바닥 / 20년+ 설비·전기 / 25년+ 샷시 검토)
  - 전유면적 vs 실측면적 대조 = "대장 84.9㎡ / 실측 82.3㎡" (실측의 가치 시각화)
- 프록시 워커 `/v1/building` 라우트 경유(키 은닉). juso.go.kr 주소검색 API로 주소→지번 변환.
