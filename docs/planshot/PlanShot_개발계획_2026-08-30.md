# PlanShot 개발 계획 — 제안서(260813 v2) 약속 vs MoveViz-core 현재 상태

작성 2026-08-30. 입력: `PlanShot_제안서_260813_full_v2.pdf`(27p, Part1 개인업체용 19p + Part2 B2B 8p) × `14_MoveViz-core` 코드(2026-08-30 초기 커밋).

## 0. 한 줄 판단

제안서는 MoveViz(이사 견적)를 **PlanShot(인테리어 실측·수주 도구)** 로 피벗한다. 약속의 핵심 3가지 중
- **② 한국식 도면(이중선 벽·문 스윙·창 3선·mm 치수)** — iOS `FloorPlanView`가 이미 70% 구현 ✅
- **① 온디바이스 15분(스캔→도면→물량, 서버 없음)** — RoomPlan 경로만 온디바이스, 메시 경로는 맥 서버 필수 ⚠️
- **③ 공내역(물량 산출) xlsx** — **0%**. `QuoteEngine`은 이사 견적(부피→톤수)이라 도메인이 다름 ❌

→ 결론: **RoomPlan을 제품의 정본 경로로 삼고, 도면 마감(PDF/타이틀블록/평수) → 공내역 엔진 → DXF/결제 순**으로 간다. 약 2개월(1인)이면 제안서 p2 데모("15분 내 카톡 PDF")를 실제로 시연할 수 있다.

## 2. 먼저 확정할 결정 (D1~D5)

- **D1 정본 경로 = RoomPlan(온디바이스).** 제안서 p8 "맥·서버 없이 폰 단독"을 지키는 유일한 현실 경로. 메시 파이프라인(v4/v5, 맥)은 검증·비교용. 근거: `SPIKE_README` 3기준, 폴리캠 갭분석 S1, RoomPlan 메모 "듀얼트랙". ⚠️ 스파이크 실측 결과(`roomplan_spike_report.json`)가 저장소에 없다 → Phase 0에서 숫자로 확정.
- **D2 벽 두께 표시 200mm 고정**(README_CAD 결정 유지). 물량은 **내측 치수** 기준.
- **D3 공내역 v1 범위** = 바닥/천장 면적, 벽 순면적(둘레×천장고−개구부), 걸레받이·몰딩 길이, 문/창 개소, 욕실 타일 면적. 단가 자동 제공 없음(p8).
- **D4 요금**: 베타 기간 결제 미구현(수동 청구), 워터마크만. StoreKit2는 Phase 3.
- **D5 리브랜딩**: 신규 앱(PlanShot 번들) vs MoveViz 갱신 — 사용자 결정. 이사 견적(`QuoteEngine`)은 숨기되 삭제하지 않음.

### Phase 1 — 베타 MVP "스캔 → 도면 PDF → 카톡" (3~4주) ← 제안서 p2 데모 그대로
1. [ ] **앱 흐름 재편** (`RootTabView`, `ModePickerView`): 프로젝트(세대) → 방 목록 → 스캔(RoomPlan) → 도면 → 내보내기. 맥 업로드·카메라 모드는 "실험" 메뉴로 숨김
2. [ ] **Project 모델**: `{주소, 단지/동/호, 평형, 고객명, rooms:[SavedScan+방이름]}` — `ScanStore` 위에 추가, 방 이름 프리셋(침실1·거실·주방·욕실·현관)
3. [ ] **세대 합산**: 방별 면적 합 → ㎡·평, 천장고 = RoomPlan floor/ceiling(하드코딩 2.4 제거). v1은 **방별 도면 페이지**(좌표 정합은 Phase 3)
4. [ ] **도면 마감** (`FloorPlanView`): 평수, 방 이름, 실별 내측 치수, 천장고, 타이틀블록(업체·고객·주소·날짜·축척), 푸터 "개략 실측 — 시공 발주 전 정밀실측 필요"
5. [ ] **치수 수동 보정**: 벽 탭 → 레이저 값 입력 → 해당 벽/전체 스케일 보정 (p11 스팟 보정). 보정 여부를 도면에 표기
6. [ ] **PDF 내보내기**: A4 방별 페이지 + 세대 요약 페이지, 워터마크(무료), `UIActivityViewController`로 카톡 공유
7. [ ] **오프라인 보장**: `ScanUploader` 호출 전부 옵션화, 서버 미설정 시 UI 노출 안 함
8. [ ] 실기기 QA: iPhone Pro(iOS 17+) — 거울/유리 방 포함, 3세대 이상

**DoD**: 실제 아파트 1세대(방 5개) **15분 내 스캔→PDF→카톡** 성공 + 레이저 대조 오차표 첨부.

### Phase 2 — 공내역(물량 산출) + xlsx (3~4주)
1. [ ] **BOQ 데이터 모델** (`BOQEngine.swift` 신규): 실별 {바닥면적, 천장면적, 둘레, 벽 순면적, 걸레받이 길이(둘레−문 폭), 몰딩 길이, 문 개소, 창 개소}, 욕실 {벽타일·바닥타일 면적}. 빌트인 철거/보존 토글 → 벽면적 공제
2. [ ] **내역 템플릿**: 제안서 p6 서식(공종·품명·규격·단위·수량·재료비·노무비·합계·비고), 기본 5공종(철거/도배/바닥/목공/욕실), 항목별 산식 매핑, 규격 편집 가능. "실측 자동"/"개소 자동 인식" 비고 표기
3. [ ] **단가표**: CSV/xlsx 가져오기 또는 직접 입력, 로컬 저장. 금액=수량×단가, 미입력은 빈칸
4. [ ] **xlsx writer**: 순수 Swift OOXML(zip+sheet xml) 또는 경량 패키지 — 엑셀·구글시트에서 열리는지 검증. PDF 내역서 병행
5. [ ] 공내역 화면: 실 목록 → 수량 확인/수정 → 내보내기(xlsx·PDF)
