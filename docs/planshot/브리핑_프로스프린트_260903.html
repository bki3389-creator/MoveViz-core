즉, 누구든 링크만 열면 키 입력 없이 AI 디자이너가 작동하게 만드는 중계 서버 1개를 띄우는 일입니다. 코드는 이미 다 작성돼 repo에 있습니다(infra/ai-proxy/) — 남은 건 계정 작업뿐:

1
Cloudflare 무료 계정 (있으면 생략)
2
wrangler login → wrangler deploy → wrangler secret put ANTHROPIC_API_KEY (키 입력)
3
나온 워커 주소를 js/config.js의 AI_PROXY_URL에 붙여넣고 푸시 → 끝

비용: Worker는 무료 티어로 충분. AI 호출 비용만 내 키로 결제되는데 하루 30회/IP 리밋이 상한을 잡습니다. 5~10분 작업.
