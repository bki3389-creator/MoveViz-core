# PlanShot 해커톤 전략 — 오늘의창업 / 원티드 해커톤 (2026-09-03)

라이브 데모: https://bki3389-creator.github.io/MoveViz-core/?sample

## 0. 한 줄 포지셔닝

> **"아이폰으로 3분 실측하면 — 도면·물량·견적·3D·AI 디자인까지, 인테리어의 시작이 끝난다."**

같은 엔진, 두 얼굴: 소비자에겐 **"견적이 처음으로 이해되는 앱"**, 시공자에겐 **"실측 방문 한 번이 계약서가 되는 도구"**.

## 1. 문제 (피치 1장)

| 쪽 | 고통 | 지금 대안의 한계 |
|---|---|---|
| 소비자 | 같은 집에 업체별 견적 2~3배 차이. 실면적·물량을 모르니 비교 불가. 구축 주택은 도면 자체가 없음 | 아파트 도면 DB는 '표준 평면'이지 우리 집 실측이 아님. 3D 홈앱은 예쁘기만 하고 견적·도면 발행 없음 |
| 시공자(1~5인) | 실측 방문→수기 도면→견적서 작성 = 반나절~하루. CAD 못 쓰는 1인 사업자 다수. 마감 합의는 사진 몇 장 → 분쟁 | 실측 장비(라이카 등)는 수백만 원. 도면 외주는 건당 비용+왕복 시간 |

## 2. 두 모드 설계 (핵심 작업 축)

### A. 내 집 모드 (사용자)
- **페르소나**: 이사·셀프인테리어를 앞두고 "업체 만나기 전 기준"이 필요한 30대.
- **여정**: 스캔(또는 샘플) → 우리 집 3D 산책(F4) → "거실을 우드 미니멀로" AI 대화 → 비포/애프터 → 예상 비용 범위 → 업체에 보낼 **실측 리포트 링크** 공유.
- **매력포인트 우선순위**
  1. **AI와 대화하면 내 집이 바뀐다** — 시점 캡처→제안 칩→[모두 적용]→3D·견적 동시 갱신 (시연 킬샷)
  2. **견적의 번역** — "평당 얼마"가 아니라 "우리 집 벽 실면적 X㎡ × 자재/노무 단가" 근거 전부 공개
  3. 걷기 몰입감 + 실사 렌더샷
  4. 가구 라이프사이클 — 폐기 반출 톤·신규 구매까지 한 견적서에
- **작업**: 전문용어 쉬운말 치환(걸레받이→바닥 테두리), 자재 등급 슬라이더로 총액 변동, 읽기전용 공유 리포트.

### B. 프로 모드 (일하는 사람)
- **페르소나**: 1인~5인 인테리어/도배/필름/목공 사업자. (확장: 부동산 매물 도면, 이사업체 반출량)
- **여정**: 현장 스캔 → 즉석 도면+물량산출 → 고객 앞에서 3D로 마감 확정 → 브랜딩 견적서 발행 → 협력업체에 DXF 전달.
- **매력포인트 우선순위**
  1. **물량산출 자동화** — 벽·천장·바닥 실면적, 개구부 공제, 가벽 양면, 걸레받이·몰딩 길이. 노드 테스트 100+ 어서션으로 재검산 (엔진의 진짜 해자)
  2. **실무 표준 DXF** — A-CON/A-FIN 레이어 체계, 치수 2단, A3 도곽·표제란 (업계 심사위원에게 강력)
  3. 내 단가표 저장 + 마진 + 회사 로고 견적서
  4. **고객 제안 링크** — 고객이 폰에서 3D 보고 마감을 고르면 견적 자동 갱신 → 계약 전환율
- **작업**: 단가표 관리 UI, 견적서 PDF 발행, 회사 프로필.

## 3. 대회별 각도

| | 원티드 해커톤 (AI 중심 예상) | 오늘의창업 (사업성 중심 예상) |
|---|---|---|
| 주인공 | **AI 디자이너** — 멀티모달(시점 캡처 vision) + 구조화 출력(JSON 변경안) + 도메인 그라운딩(실측 좌표·카탈로그 id) = "AI가 장난감이 아니라 견적서까지 연결" | **양면 시장** — 프로가 매일 쓰는 도구(B2B SaaS 구독) + 소비자 실측 리포트가 시공 리드가 되는 구조(중개/제휴 수익) |
| 첫 장 | 대화 한 줄에 3D와 견적이 동시에 변하는 GIF | 견적 2~3배 편차 캡처 + 실측 병목 비용 수치 |
| 강조 기술 | RoomPlan LiDAR→웹BIM→패스트레이싱→Claude vision 풀스택 | 물량산출 엔진 검증(테스트 스위트), 실무 DXF 표준 → "업계가 바로 쓸 수 있음" |

**⚠ 요강·마감일 미확인** — 공고 링크 확보 즉시 일정 역산·제출물 양식 맞춤 작성.

## 4. 데모 시나리오 (3분 역산)

```
0:00 문제 1장 — 같은 집 견적 3배 차이
0:20 아이폰 스캔 영상 10초 (사전 촬영)
0:30 링크 열기 → 실측 도면이 바로 떠 있다
0:50 F4 걷기 — 내 집을 걸어본다
1:10 📍시점 캡처 → "우드+베이지 미니멀, 간접등 위주로" → 제안 칩 → [모두 적용] → 눈앞에서 변신
1:40 견적 패널 — 방금 적용으로 금액이 바뀌었다 (마루 교체 +N원, 근거 행 노출)
2:00 프로 모드 전환 — 물량산출 CSV + 실무 DXF를 캐드로 연다
2:30 사전 렌더 고품질 컷 + 비즈니스 모델 1장
```
백업: 전 과정 녹화본 1개(네트워크·GPU 사고 대비), 로컬 serve.py 오프라인 데모.

## 5. 개발 백로그 (우선순위)

### P0 — 데모 성립 필수
1. **AI 프록시** — 지금은 개인 API 키 입력 구조라 심사위원이 못 씀. Cloudflare Worker(데모 키+레이트리밋 일 N회) 경유, 프론트에 프록시 폴백. *가장 급함*
2. **모드 스위치** — 첫 진입에서 "내 집 / 프로" 선택 → 용어·패널·기본 화면 분기 (엔진 동일)
3. **온보딩** — 링크 열면 샘플 즉시 로드 + "내 스캔 올리기" 드래그 안내 1장
4. **아이폰 사파리 대응** — 심사위원은 폰으로 연다 (입력창 16px·safe-area·탭영역 체크리스트)
5. **실측 데이터 갤러리** — iOS 빌드가 늦으면 실제 집 2~3곳 사전 스캔 plan.json 내장
### P1 — 모드별 매력 완성
6. 비포/애프터 슬라이더 (AI 적용 전후)
7. 내집=쉬운말 견적 / 프로=단가 편집·로고 견적서
8. 읽기전용 공유 리포트 링크
9. 렌더 갤러리 (고품질 사전 렌더 보관·발표 재사용)
### P2 — 가산점
10. 2단계 AI 리스타일(ControlNet — 로드맵 문서 있음)
11. 발표자료·1분 티저 영상
12. 사용 지표 화면(스캔 수·견적 발행 수)

## 6. 피치 덱 골격 (10장)
문제 → 시장(국내 인테리어·리모델링 규모, 실측 병목) → **라이브 데모** → 기술(LiDAR+웹BIM+AI 풀스택, 검증 스위트) → 왜 지금(LiDAR 보급 + LLM 비전) → 양면 BM(프로 구독 + 리드 수수료) → 경쟁 비교표(도면DB형/3D홈앱형/CAD형과 4분면) → 로드맵(iOS 정식→프로 정산) → 팀 → 요청사항.

## 7. 리스크와 대비
- iOS 빌드 미검증 → 데모는 웹+사전 스캔으로 완결 (스캔은 영상으로)
- AI 키·비용 → 프록시 + 레이트리밋 + 데모 대사 고정(응답 캐시)
- 렌더 GPU 편차 → 사전 렌더 백업, 시연은 raster+걷기 위주
- 심사장 네트워크 → 로컬 서버 + 녹화본
