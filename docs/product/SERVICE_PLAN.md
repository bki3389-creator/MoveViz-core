# MOVEVIZ 서비스 계획 — 스캔 → 가구 추출 → 이사 견적 → 평면 배치

작성 2026-07-06. 목표: 기존 파이프라인(스캔→평면도→가구 검출)을 소비자 서비스로 완성.
킥오프 회의(2026-03-11)의 A(가구추출)/B(배치)/C(출력) 구도를 계승 — A는 구축 완료, 이제 B·C.

## 0. 현재 보유 자산 (완료된 것)

| 자산 | 상태 |
|---|---|
| 스캔 캡처 (LiDAR / RoomPlan / 비-라이다 카메라 VIO) | ✅ 앱 배포됨 |
| 평면도 추출 (서버 v4 합의 벽 + 온디바이스 RoomPlan) | ✅ (프로토타입 문서: claude.ai 아티팩트) |
| 가구 검출: 카테고리 + 실측 치수 + 회전 (OWLv2) | ✅ 검출 3→13개로 개선, 중복 병합은 Phase 2 |
| 가구 정제 3D 모델 생성 (카테고리별 GLB) | ✅ furniture_models.py |
| 앱 평면도 렌더러 (건축식: 치수선·벽밴드·문/창·가구 심볼) | ✅ FloorPlanView |
| 텍스처드 3D + 원본 메쉬 뷰어, '내 스캔' 보관함 | ✅ |

## 1. 서비스 흐름 (사용자 관점)

```
① 집 스캔 (방마다) ─→ ② 가구 인벤토리 자동 생성 (치수·부피 포함, 수정 가능)
        │                          │
        │                          ▼
        │                 ③ 이사 견적 (부피→톤수→차량→가격범위 + 특수품/할증)
        ▼                          │
④ 새집 평면도 (스캔 or 도면) ←──────┘
        │
        ▼
⑤ 평면 배치: 내 가구를 새집 평면도에 드래그 배치 (충돌·통로 검사)
        │
        ▼
⑥ 출력: 견적서 + 배치도 공유 (이사업체 전달용)
```

## 2. 구성 요소별 계획

### ② 가구 인벤토리 (iOS: InventoryView)
- 데이터: 스캔별 furniture_vision.json (category, dims, yaw) → 집 단위로 합산
- 항목별: 한글명·치수(cm)·부피(㎥)·수량, 스와이프 삭제, 수동 추가(카테고리+치수 프리셋)
- 다중 스캔(방 여러 개) 합치기: scan id 목록 → 통합 인벤토리
- 저장: Documents/inventory.json

### ③ 이사 견적 엔진 (서버: quote_engine.py + /quote API, 앱: QuoteView)
- 모델: Σ(가구 부피) × 포장/여유 계수 → 총 짐량(㎥) → 톤수/차량 매핑 → 가격 범위
- 계수·단가: **리서치 진행 중** (한국 이사업계 짐량표·톤수 기준·2025-26 가격대) → 확정되면 여기 기록
- 할증 입력: 층수/엘리베이터, 사다리차, 거리, 손없는날, 에어컨·피아노 특수품
- 출력: 추정 톤수, 권장 차량, 가격 범위(포장/반포장/일반), 면책 문구("실사 후 확정")
- 앱 화면: 인벤토리 요약 → 옵션 토글 → 견적 카드, "견적서 공유"(PDF/이미지)

### ⑤ 평면 배치 (iOS: PlacementView — FloorPlanView 확장)
- 입력: 대상 평면도(PlanData) + 인벤토리 가구
- 인터랙션: 가구 팔레트에서 탭 → 평면 위 드래그 이동 / 회전(45° 스냅) / 삭제
- 검사: 가구-벽/가구-가구 겹침 경고(빨강), 문 스윙 반경 침범 경고
- 저장/공유: 배치 결과를 PlanData.furniture로 직렬화 → 이미지 내보내기

### ⑥ 출력
- 견적서: 인벤토리 표 + 견적 + 배치도 이미지 1장 → 공유 시트
- (후순위) 업체 전달용 웹 링크: 맥 서버가 scans/<id>/share.html 생성

## 3. 마일스톤

1. **M1 견적 코어**: 리서치 계수 확정 → quote_engine.py + /quote/<id> + 앱 인벤토리·견적 화면
2. **M2 배치**: PlacementView (드래그·회전·충돌) + 배치 저장/공유
3. **M3 출력·다듬기**: 견적서 공유, 다중 방 인벤토리 합산, 중복 가구 병합(평가셋 후)

## 4. 리스크 / 미결

- 가구 중복 검출(욕조×4)이 인벤토리·견적을 부풀림 → M1에서 임시로 "동일 카테고리 근접 병합(보수적)" + 사용자 삭제 UI로 방어, 근본 해결은 평가셋 후
- 치수 절대 정확도 미검증(줄자 대조 필요) → 견적은 "범위"로 표기해 흡수
- 비-라이다 스캔 실기기 왕복 테스트 미실시

## 5. 이사 견적 계수 (리서치 확정, 2026-07-06)

- 짐량: `V = Σ(실측 w×h×d × 포장계수) × 1.35(잡짐)` — 포장계수: 가구 1.15 / 가전 1.2 / TV·유리 1.3
- 톤수: `V / 5㎥` → 티어 [1, 1.4, 2.5, 3.5, 5, 6, 7.5, 10톤] (1톤 트럭 실효 적재 ≈5㎥; 30평 4인 ≈30CBM≈5~6톤 앵커로 검증)
- 가격(서울, 만원): 1톤 일반15-30/반포장20-40/포장30-50 · 2.5톤 40-60/65-85/80-100 · 3.5톤 55-75/75-100/90-120 · 5톤 70-100/85-120/95-150 · 6톤+ 90-130/110-170/120-200
- 할증: 사다리차 12만~(5층+ 층당 +1만), 엘베없음 +15만(인부), 손없는날/주말 +10~30%, 성수기(2-4·9-11월) +20~30%, 장거리 100km당 +10~15만, 에어컨 이전설치 벽걸이 7-15/스탠드 10-18만, 피아노 15-50만
- 고지: "추정치, 실사 후 확정" / 표준약관(사전고지 없는 추가요금 무효, 계약금 10%, 취소 위약금 단계) 표기
- 차별점: 짐싸/내집이사 등은 사진·자가입력 기반 — **3D 스캔 실측 기반 자동견적은 없음**
